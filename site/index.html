Eliahou Collatz Bounds

Lean 4 formalization of Eliahou's 1993 results on Collatz cycle lengths (The 3x+1 problem: new lower bounds on nontrivial cycle lengths, Discrete Mathematics 118).

Scope — Theorem 1.1 (full linear form)

For an exact (injective) compressed Collatz cycle Ω with min Ω > 240, 

Card Ω = 301994·a + 17087915·b + 85137581·c

for some a, b, c ≥ 0 with b > 0 and a·c = 0. As a corollary, every such cycle has length at least 17,087,915.

Paper-facing statements live in Results.lean and Collatz/LinearForm.lean. Large power comparisons and Farey identities use norm_num (raised exponentiation.threshold); no native_decide remains.

Building

Depends on Mathlib (Lean v4.28.0 as locked in lean-toolchain on main). Prefer pre-built caches: 

git clone https://github.com/tangentproofs/eliahou-collatz-bounds.git
cd eliahou-collatz-bounds
lake exe cache get   # download Mathlib oleans — do not build from scratch
lake build
If lake exe cache get fails, ensure curl/wget are available and the toolchain matches lean-toolchain.
